Connect to REAPER
  1. Add a Web browser interface in REAPER preferences.
  2. Click User pages and copy the entire project folder into that directory.
  3. Enable port 9090, click OK to save and close preferences, then open the address below.
http://127.0.0.1:9090/reaper-lyrics/index.html

On older REAPER versions, avoid Apply settings followed by OK. If a port error appears, close preferences before checking the connection.

See README.md for full instructions. Audio plays in REAPER.

How to record

In REAPER, choose a recording track, set its input, and enable Record Arm. Selecting the track alone is not enough.

REAPER records all armed tracks. Disarm any tracks you do not want to record. Click Stop to finish, then follow REAPER’s prompts to save the recording.

Lyrics are saved only in this browser
